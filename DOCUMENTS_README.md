# 📄 Функциональность формирования документов аренды

## Описание

Система автоматического формирования трех официальных актов при выполнении операций аренды:

1. **Акт передачи инвентаря** - документ о передаче товара со склада арендатору
2. **Акт выдачи инвентаря** - подтверждение получения товара арендатором  
3. **Акт приемки инвентаря** - documento о возврате товара в конце периода аренды

## Как использовать

### 1. В интерфейсе приложения

#### Шаг 1: Выберите аренду
- Перейдите на вкладку **"Аренда"**
- Найдите нужную аренду в таблице
- Установите флажок рядом с аредой (выберите только одну!)

#### Шаг 2: Нажмите кнопку
- Нажмите на зеленую кнопку **"Сформировать документы"**

#### Шаг 3: Выберите документы
- В открывшемся окне выберите, какие документы нужно скачать
- Все три по умолчанию выбраны
- Вы можете отключить любой из них

#### Шаг 4: Скачайте
- Нажмите **"Скачать выбранные"**
- Документы начнут скачиваться автоматически

### 2. Содержание документов

Каждый PDF-документ включает:

```
- Номер документа (уникальный, автоматически генерируется)
- Дата создания документа
- Наименование товара/инвентаря
- Категория (Мебель, Экспонаты, Инструменты и т.д.)
- Количество единиц
- ФИО или название организации арендатора
- Дату начала и окончания периода аренды
- ФИО ответственного сотрудника
- Поля для подписей всех сторон
```

## Технические детали

### Структура кода

#### Frontend (JavaScript)
- **documents-generator.js** - основной модуль для генерации PDF
  - `generateDocumentsModal()` - открыть окно выбора документов
  - `generateTransferAct()` - создать акт передачи
  - `generateIssuanceAct()` - создать акт выдачи
  - `generateAcceptanceAct()` - создать акт приемки
  - `downloadSelectedDocuments()` - скачать выбранные документы

#### Backend (Node.js/Express)
- **routes/documents.js** - API endpoints для работы с документами
  - `GET /api/documents/:rentalId` - получить данные для конкретной аренды
  - `GET /api/documents/generate/:rentalId` - получить подготовленные данные для документов

#### Database
- Используется информация из таблиц:
  - `rentals` - основные данные аренды
  - `inventory` - информация о товарах

### Используемые библиотеки

- **jsPDF** - создание PDF документов
- **html2canvas** - преобразование HTML в изображения (для сложных макетов)
- **html2pdf.js** - комбо-решение HTML to PDF

## Примечания и рекомендации

### Для пользователей

1. **Убедитесь, что выбрана одна аренда**
   - Если не выбрано документов, система выдаст предупреждение
   - Если выбрано больше одной аренды, система также предупредит

2. **Проверьте данные перед скачиванием**
   - Убедитесь, что в одной из строк таблицы указаны все нужные данные (арендатор, дата, ответственный)
   - Заполните необходимые поля в форме добавления/редактирования аренды

3. **Номера документов**
   - Каждый документ получает уникальный номер вида: АКТ-YYYYMM-XXXXX
   - Это помогает отслеживать документы

4. **Печать**
   - Документы рекомендуется распечатывать на листах формата A4
   - Используйте функцию печати браузера (Ctrl+P / Cmd+P)
   - Установите ориентацию "Книжная"

### Для разработчиков

1. **Расширение функциональности**
   - Можно добавить дополнительные поля в документы
   - Можно изменить стиль/оформление (шрифты, цвета, размеры)
   - Можно добавить логотип компании в заголовок

2. **Интеграция с базой данных**
   - API endpoints уже подготовлены для получения данных из PosgreSQL
   - Можно синхронизировать номера документов в базе

3. **Кастомизация**
   - Отредактируйте функции `generateTransferAct()`, `generateIssuanceAct()`, `generateAcceptanceAct()`
   - Измените стили, добавьте информацию о компании, логотип и т.д.

## Примеры кода для расширения

### Добавление логотипа в документ

```javascript
// В начало функции generateTransferAct()
const logoImg = new Image();
logoImg.src = 'logo.png'; // путь к логотипу
// использовать addImage() в jsPDF
```

### Добавление дополнительной информации

```javascript
// Добавить в documento информацию о реквизитах компании
doc.text('ООО "Наша Компания"', margin, yPosition);
doc.text('ИНН: 7707083893', margin, yPosition + lineHeight);
doc.text('ОГРН: 1077746000094', margin, yPosition + lineHeight * 2);
```

### Сохранение номера документа в базу

```javascript
// На бэкенде, после создания документа
await pool.query(
  'INSERT INTO documents (rental_id, doc_number, doc_type, created_at) VALUES ($1, $2, $3, NOW())',
  [rentalId, documentNumber, 'transfer']
);
```

## Контроль качества

### Тестирование

1. Убедитесь, что все три документа скачиваются
2. Проверьте корректность заполнения данных в документах
3. Откройте PDF в разных читалках (Adobe Reader, браузер, etc.)
4. Проверьте печать на физический носитель

### Исправление ошибок

Если документы не скачиваются:
1. Проверьте браузер на наличие расширений, блокирующих скачивания
2. Проверьте консоль браузера (F12) на ошибки
3. Убедитесь, что выбрана только одна аренда
4. Заполните все необходимые поля в форме аренды
