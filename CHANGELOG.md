## 🚀 Как использовать

### Для конечного пользователя

1. Перейти на вкладку **"Аренда"**
2. Выбрать одну аренду (чекбокс слева)
3. Нажать зеленую кнопку **"Сформировать документы"**
4. Выбрать нужные документы
5. Нажать **"Скачать выбранные"**
6. Документы скачаются в папку Downloads

### Для разработчика

```javascript
// Открыть модальное окно
generateDocumentsModal();

// Генерировать конкретный документ
await generateTransferAct(rentalObject);
await generateIssuanceAct(rentalObject);
await generateAcceptanceAct(rentalObject);

// Скачать выбранные документы
downloadSelectedDocuments();
```

## 🎨 Внешний вид документов

### Каждый документ содержит:

1. **Заголовок** (растянут на всю ширину)
   - Название (АКТ ПЕРЕДАЧИ ИНВЕНТАРЯ и т.д.)

2. **Метаданные**
   - Номер документа (АКТ-YYYYMM-XXXXX)
   - Дата составления

3. **Основная информация** (структурированные блоки)
   - Информация об объекте аренды
   - Информация об арендаторе
   - Период аренды
   - Ответственное лицо

4. **Подписи** (в конце документа)
   - Поле для подписи компании
   - Поле для подписи арендатора
   - Места для ФИО и даты

5. **Подвал**
   - Номер документа (серым цветом)

## 🎯 Рекомендации по использованию

3. Установите ориентацию "Книжная"

## 🐛 Известные ограничения

1. **Сохранение номеров в БД**
   - Номера документов генерируются клиентом
   - Не сохраняются в базе (требует доп. работы)

2. **Электронные подписи**
   - Сейчас только печатная форма
   - Можно добавить позже через ЭЦП

3. **Шаблоны**
   - Жестко кодированы в функциях
   - Можно сделать динамическими через админ-панель

4. **Отправка по Email**
   - Не реализована
   - Требует интеграции nodemailer
