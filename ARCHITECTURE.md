## Поток данных при создании документа

```
Пользователь выбирает аренду
          ↓
┌─────────────────────────────────────────┐
│ Нажимает "Сформировать документы"       │
└────────────────────┬────────────────────┘
                     ↓
┌─────────────────────────────────────────┐
│ generateDocumentsModal()                 │
│ - Получает индекс из checkbox           │
│ - Найти rental из массива rentals       │
│ - Показать информацию в модальном окне  │
└────────────────────┬────────────────────┘
                     ↓
┌─────────────────────────────────────────┐
│ Пользователь выбирает документы         │
│ и нажимает "Скачать выбранные"          │
└────────────────────┬────────────────────┘
                     ↓
┌─────────────────────────────────────────┐
│ downloadSelectedDocuments()              │
│ - Проверить выбранные документы         │
│ - Вызвать функции генерации             │
└────────────────────┬────────────────────┘
                     ↓
         ┌───┬───────┴────────┬───┐
         ↓   ↓                ↓   ↓
    ┌─────┴─┐ ┌─────────────┐ ┌─────────────┐
    │Transfer│ │  Issuance   │ │ Acceptance  │
    │  Act   │ │    Act      │ │    Act      │
    └────┬───┘ └──────┬──────┘ └──────┬──────┘
         │            │               │
         ↓            ↓               ↓
    generateTransfer generateIssuance generateAcceptance
    Act(rental)      Act(rental)      Act(rental)
         │            │               │
         └────┬───────┴───────────┬───┘
              ↓                   ↓
    ┌─────────────────────────────────┐
    │ doc.save('filename.pdf')         │
    │ - Инициализировать jsPDF doc    │
    │ - Добавить содержание           │
    │ - Скачать как файл              │
    └───────────┬─────────────────────┘
                ↓
    ┌──────────────────────────────────┐
    │ PDF файл скачивается             │
    │ в папку Downloads пользователя   │
    └──────────────────────────────────┘
```

## Жизненный цикл документа

```
ЭТАП 1: ИНИЦИАЛИЗАЦИЯ
└─ Пользователь открывает вкладку "Аренда"
   └─ renderRentalsTable() заполняет таблицу

ЭТАП 2: ВЫБОР
└─ Пользователь выбирает аренду (checkbox)
   └─ currentRentalForDocuments = rentals[index]

ЭТАП 3: ОТКРЫТИЕ МОДАЛЬНОГО ОКНА
└─ generateDocumentsModal() вызывается
   ├─ Проверка: выбрана ли одна аренда
   └─ Отображение информации в окне

ЭТАП 4: ВЫБОР ТИПОВ ДОКУМЕНТОВ
└─ Пользователь выбирает нужные типы
   ├─ docTransfer.checked = true/false
   ├─ docIssuance.checked = true/false
   └─ docAcceptance.checked = true/false

ЭТАП 5: СОЗДАНИЕ PDF
└─ downloadSelectedDocuments() вызывается
   ├─ if (docTransfer) → generateTransferAct()
   │  ├─ new jsPDF()
   │  ├─ doc.text() (добавить текст)
   │  └─ doc.save() (скачать)
   │
   ├─ if (docIssuance) → generateIssuanceAct()
   │
   └─ if (docAcceptance) → generateAcceptanceAct()

ЭТАП 6: СКАЧИВАНИЕ
└─ Браузер скачивает файлы в Downloads
   ├─ Акт передачи инвентаря - АКТ-YYYYMM-XXXXX.pdf
   ├─ Акт выдачи инвентаря - АКТ-YYYYMM-XXXXX.pdf
   └─ Акт приемки инвентаря - АКТ-YYYYMM-XXXXX.pdf

ЭТАП 7: ИСПОЛЬЗОВАНИЕ
└─ Пользователь может:
   ├─ Распечатать документы
   ├─ Отправить по email
   ├─ Сохранить в архив
   └─ Подписать рукописью
```

## Граничные условия обработки

```
Пользовательское действие          Проверка              Результат
─────────────────────────────────────────────────────────────────

Нажать кнопку без выбора    → No checkbox selected  → showNotification
                               (warning)

Выбрать >1 аренду           → checkboxes.length > 1 → showNotification
                               (warning)

Не выбрать ни одного документа → All unchecked      → showNotification
                                 (warning)

Не заполнить данные аренды  → Missing field data    → Использовать
                                                      значение по умолчанию

Ошибка при генерации PDF    → catch (err)           → showNotification
                                                      (error) + console.log

Успешно создан документ     → doc.save() success    → close modal +
                                                      showNotification (success)
```
