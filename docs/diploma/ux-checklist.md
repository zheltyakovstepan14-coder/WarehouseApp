# UX regression checklist (smoke)

## Вкладки и читаемость
- [x] Склад: видны фильтры, таблица, бейджи статусов, массовая панель.
- [x] Аренда: видны кнопки действий, статусы, поля фильтра и placeholder.
- [x] Мероприятия: консистентные кнопки и статусные бейджи, читаемые таблицы.
- [x] Документы: заголовки таблицы, фильтры, статусы и действия читаемы.
- [x] История: фильтры и результаты контрастны и единообразны.
- [x] Пользователи: таблица и заголовки в едином стиле с остальными разделами.

- [x] Пустые состояния содержат полезную подсказку, а не только факт отсутствия данных.
- [x] Недоступные кнопки показывают причину через tooltip.
- [x] Базовый onboarding показывается один раз после первого успешного входа.
- [x] Панель уведомлений подсвечивает приоритеты и дает быстрый переход к действию.
