## 🔗 API RBAC:

```javascript
// Инициализация при входе
RBAC.initializeUser(userData)

// Проверка прав
RBAC.hasPermission('stock', 'create')  // true/false

// Получить текущего пользователя
RBAC.getCurrentUser()

// Управление правами
RBAC.setUserCustomPermissions(userId, permissions)
RBAC.loadUserCustomPermissions(userId)
RBAC.resetUserCustomPermissions(userId)

// Получить информацию о правах
RBAC.getUserPermissions(role, customPermissions)
RBAC.getDefaultPermissionsForRole(role)
RBAC.getAvailableRoles()
```

## 📝 Примеры интеграции:

### Пример 1: Проверка перед действием
```javascript
async function createRental(data) {
  if (!RBAC.hasPermission('rental', 'create')) {
    showNotification('Недостаточно прав для создания аренды', 'error');
    return;
  }
  // ... создание аренды
}
```

### Пример 2: Скрытие кнопки
```javascript
function updateUIByPermissions() {
  const addBtn = document.getElementById('addRentalBtn');
  if (RBAC.hasPermission('rental', 'create')) {
    addBtn.style.display = 'inline-block';
  } else {
    addBtn.style.display = 'none';
  }
}

// Вызвать после загрузки страницы
document.addEventListener('DOMContentLoaded', updateUIByPermissions);
```
