## 🚀 Быстрый старт

### 1. Убедитесь, что зависимости установлены

```bash
cd d:\ВКР\WarehouseApp
npm install jspdf html2canvas
```

### 2. Запустите приложение

```bash
npm start
```

Приложение будет доступно по адресу: **http://localhost:3002**

### 3. Используйте новую функцию

1. Перейдите на вкладку **"Аренда"** (главное меню)
2. Выберите одну аренду (галочка слева)
3. Нажмите зеленую кнопку **"Сформировать документы"**
4. Выберите нужные документы и нажмите **"Скачать выбранные"**
5. PDF файлы скачаются в папку Downloads

## 💡 Примеры использования

### Базовой использование
```javascript
// 1. Открыть окно выбора документов
generateDocumentsModal();

// 2. Скачать выбранные документы
downloadSelectedDocuments();
```

### Программное создание всех трех документов
```javascript
const rental = {
    itemName: 'Стол деревянный',
    category: 'Мебель',
    quantity: 1,
    renter: 'Иванов И.И.',
    rentDate: '2024-03-01',
    returnDate: '2024-03-15',
    responsible: 'Петров П.П.'
};

// Создать документы
await generateTransferAct(rental);      // Передача
await generateIssuanceAct(rental);      // Выдача
await generateAcceptanceAct(rental);    // Приемка
```

## 📞 Если что-то не работает

### Проверьте:
1. **Консоль браузера** - F12 → Console (ошибки)
2. **Логи сервера** - в терминале где запущен npm
3. **Файлы** - все ли файлы на месте
4. **Данные** - заполнены ли все поля в аренде
5. **Браузер** - попробуйте другой браузер

### Типичные ошибки:

**"Не выбрана аренда"**
→ Закрасьте чекбокс рядом с одной из строк таблицы

**"Выберите хотя бы один документ"**
→ Отметьте галочку под одним из документов

**"Нет данных об аренде"**
→ Убедитесь, что все поля формы аренды заполнены

**Документы не скачиваются**
→ Проверьте настройки браузера (не блокирует ли скачивания)
